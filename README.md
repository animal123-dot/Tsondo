# Tsondo

Tsondo — browser music + video generator

This repo was scaffolded by GitHub Copilot Chat Assistant as a React + Vite single-page app (SPA).

Defaults:
- Deploy: GitHub Pages (gh-pages) via GitHub Actions
- Output format: WebM using MediaRecorder
- Site title: Tsondo — browser music + video generator
- Visuals: WebGL (Three.js) driven by WebAudio Analyser (planned)
- Music: Magenta.js + Tone.js in-browser generation (planned)

How to run locally:

1. Install dependencies

   npm install

2. Run dev server:

   npm run dev

3. Build:

   npm run build

Notes:
- This is an initial scaffold with a demo generate page. I will open a PR with the scaffold branch and add a GitHub Actions workflow to publish to gh-pages after the PR is merged.
